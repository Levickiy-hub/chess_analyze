# Аудит интерфейса

Единственный UI — статические HTML, сгенерированные lib/html-reporter.js. Найдены 391 файл: index.html и 390 game_N_date.html. CSS встроен, SVG генерируется строкой, JavaScript только showTooltip/hideTooltip. React/Vue, router, chessboard library, HTTP backend и запросов frontend к серверу нет. Ни один browser walkthrough не выполнялся; UI проверен по всему шаблону, существующим HTML и вызовом генераторов в памяти.

## Game review: 18 возможностей

Интерактивной доски, отображения позиции, навигации по полуходам, клавиатуры, поворота, последнего хода, стрелок, eval bar, времени на ход, просмотра PV, jump по критическим моментам/ошибкам и изучения альтернатив нет. Список SAN, bestMove UCI и данные игроков есть. График evaluation и цвета категорий существуют, но недостоверны по POV/единицам; это BROKEN, не завершённый анализ. PGN конкатенируется CLI в games.pgn, UI download/экспорта нет (BACKEND_ONLY).

Общие фильтры R6-2-*: период и профиль жёстко выбираются конфигом/каталогом, не controls; остальные 18 фильтров не реализованы. Единого query/filter service нет. Не существует сортировки/поиска по рейтингу, цвету, format, result, opening, phase, motif, session, analysis status/version.

## Подтверждённые дефекты и риски

- reporter:74–75 заменяет неизвестную/mate оценку на 0, что выглядит равной позицией; :58–59 последнему ходу приписывает pre-score.
- :101–113 добавляет фиктивную точку при пустом analysis, затем :209 делит на evalData.length-1=0: SVG содержит NaN, воспроизведено в памяти. Партия из одного полухода имеет тот же риск.
- cp значения выводятся под заголовками «пешки» без /100; знак назван POV белых, хотя движок вернул side-to-move.
- reporter:158 использует номер положительной ошибки как X, а не реальный ply; временная ось искажена.
- Имена игроков/PGN headers прямо вставляются в HTML (:387–392,455–479). Строка с img/onerror сохраняется неэкранированной; payload не исполнялся. Достижимость через ограничения имён реального Chess.com не доказывалась, но общий генератор небезопасен для недоверенного PGN.
- При date=null writer создаёт game_1_nodate.html, индекс ссылается на game_1_—.html (:456,465,535). Воспроизведено без файловой записи.
- Result='*' в UI показан как ничья, stats считает поражением.
- SVG width=800 и текст/tooltip без keyboard/touch фокуса; доступность, мобильная вёрстка и цветовой контраст не проверялись визуально.

Полезное сохранить: автономный HTML отчёт открывается без сервера, не зависит от CDN, выводит обе стороны и подсказки. В будущем это экспортный формат, а интерактивный review должен работать поверх проверенного API и DTO позиции.
