Секретов в собственном коде/конфигурации не обнаружено; скрытые external настройки аккаунта, OS backup, Defender и инфраструктура вне каталога не изучались. Изоляция username по путям не является разграничением доступа. SQL injection сейчас неприменима (нет SQL), auth не существует, сетевого inbound API нет. Это локальная программа; будущая многопользовательская безопасность требует отдельной реализации, а не признания текущих функций «безопасными» по умолчанию.
