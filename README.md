# Персональная шахматная аналитика

Локальное приложение персональной шахматной аналитики Chess.com, построенное на исходном Node.js/Stockfish проекте. Данные и вычисления остаются на вашем компьютере.

## Запуск

Нужен Node.js **24 или новее**. В этой рабочей копии зависимости уже установлены.

```powershell
cd D:\stockfish
npm start
```

Откройте **http://127.0.0.1:3000**. Остановка — Ctrl+C в терминале. Два экземпляра одновременно не запускаются. Если порт занят другим приложением:

```powershell
$env:PORT = '3001'
npm start
```

В Windows можно также запустить `Start-Chess.cmd` двойным щелчком: окно покажет адрес и сообщения приложения.

Для новой копии проекта сначала `npm ci`. Сборка frontend, Docker, PostgreSQL и Redis для локального запуска не нужны. UI работает без CDN. SQLite используется через встроенный `node:sqlite`.

`npm start`, `npm run dev` и `Start-Chess.cmd` включают системное хранилище доверенных сертификатов (`--use-system-ca`). Это позволяет Node.js доверять установленным в Windows корневым сертификатам, в том числе для HTTPS в рабочей сети. При прямом запуске используйте `node --use-system-ca index.js`. Проверка HTTPS-сертификатов Chess.com остаётся включённой. Если ошибка `unable to verify the first certificate` сохраняется, проверьте наличие корневого сертификата вашей сети в доверенном хранилище; для отдельного доверенного PEM-файла Node.js поддерживает `NODE_EXTRA_CA_CERTS`.

При первом запуске приложение переносит доступные партии из `games/` и исторические оценки из `analysis/{profile}/{month}/analysis.json` в новую `data/chess.sqlite`. Эти входные архивы сохраняются для восстановления. Исторические оценки получают исправленный POV и пересчитанные показатели; неизвестные параметры прежнего анализа явно обозначены в UI. Это не новый запуск Stockfish.

## Что можно делать

- Смотреть общую статистику, рейтинг по форматам, результаты по цветам, причины завершения, серии и продолжительность.
- Искать партии, фильтровать по периоду, формату, цвету, результату, рейтингу, сопернику, дебюту, стадии, качеству хода и источнику анализа; сортировать и листать историю.
- Сортировать таблицы нажатием на заголовок столбца: повторное нажатие меняет направление, выбранный столбец отмечен. Пустые значения остаются внизу; история партий сортируется целиком до разбивки на страницы. Порядок аналитической таблицы сохраняется при переходах между разделами и изменении фильтров в открытой вкладке.
- Разбирать партии на интерактивной доске: навигация, клавиатура, поворот, лучший ход, график оценки, часы, альтернативные ходы, MultiPV анализ позиции и экспорт PGN.
- Решать **случайные задачи из своих партий** без дневного лимита: старые задачи сохранены, следующая выбирается случайно, кнопка пополнения проверяет до пяти новых позиций Stockfish. Этот режим доступен отдельно от учебного цикла и не меняет его расписание.
- Проходить **учебный цикл** в разделе «Тренировки»: три собственные позиции за занятие, самостоятельные решения и подсказки учитываются отдельно, повторы назначаются через 10 минут или 1/2/4 дня. Исходная выборка фиксируется, затем сравнивается с новыми партиями. [Первое занятие и правила](docs/LEARNING_CYCLE.md).
- Смотреть **«Качество ходов»** в обзоре и разделе тактики: средняя точность по собственной шкале 0–100, количество классифицированных собственных ходов и доли восьми категорий. Ходы без категории показаны отдельно и исключены из процентного распределения; «Блестящий (!!)» отмечает подтверждённую жертву, «Спасение» — использование ошибки соперника для выхода из проигранной позиции. Это собственные эвристики; определения и пороги доступны в блоке «Как определяются особые ходы». Данные учитывают выбранный профиль и фильтры.
- Смотреть **«Дерево дебютов»** как схему: ход, число партий и доля побед в каждом узле. Нажатие раскрывает продолжения и обновляет позицию на доске. Глубина схемы — от 1 до 3 полуходов, на узел — от 2 до 4 самых частых ветвей; все остальные ходы доступны в таблице ниже. Проценты относятся к вашему профилю и выбранным фильтрам.
- Проверять альтернативные продолжения: выбрать ход в списке и нажать **«Заменить этот ход»**, либо начать от текущей позиции через **«Проверить другой ход»**, затем перетащить фигуру на нужное поле либо нажать фигуру и поле назначения. При перетаскивании подсвечиваются допустимые поля; отпускание вне доски или на недопустимом поле отменяет перенос. Перетаскивание также доступно в тренировках. Можно играть обе стороны вручную или запрашивать **«Ход Stockfish»**. Стрелки листают текущую линию, **«Вернуться к партии»** возвращает к точке ответвления. Разные ветки сохраняются в этом браузере по партии, доступны повторно после перезагрузки и копируются в PGN. По умолчанию после хода или перехода к позиции автоматически запускается быстрый расчёт Stockfish: оценка, лучший ответ и до трёх продолжений. Быстрый ввод откладывает запуск на 350 мс, предыдущий расчёт отменяется, а готовые результаты повторно используются в текущем разборе. Переключатель **«Авторасчёт»** запоминается в браузере; **«Остановить поиск»** отменяет текущий расчёт до следующего хода или перехода. **«Оценить позицию»** считает только текущую позицию с полной историей ходов в режиме из настроек; варианты из PV можно сыграть первым ходом или открыть целиком (до 16 полуходов). При переходе на другую позицию незавершённый запрос отменяется. Исходная партия и её статистика не изменяются.
- Оценка Stockfish берётся из завершённой итерации поиска и соответствует показанному лучшему ходу. Промежуточные границы более глубокого поиска не заменяют готовую оценку. Если для нового лучшего хода осталась только граница, при анализе партии выполняются до двух дополнительных поисков этой позиции с повышенными лимитами; граничные записи кэша повторно проверяются независимо от версии обработчика. Старые версии анализа обновляются по запросу повторного анализа, а авторасчёт на доске не заменяет категории исходной партии. Если сохранилась только граница, качество хода остаётся неизвестным. Для старого анализа с такими пропусками нажмите **«Анализировать исходную партию»**: проблемные записи кэша будут пересчитаны, предыдущая версия анализа сохранится.
- Импортировать всю доступную историю Chess.com по username и повторять синхронизацию без дублирования. Профили переключаются независимо.
- Запускать быстрый, стандартный и глубокий анализ выборки или необработанных партий; ставить на паузу, продолжать, отменять и повторять ошибки.
- Изучать репертуар и персональное дерево ходов, стадии, реализацию устойчивого преимущества и упущенные маты.
- Смотреть типы эндшпилей, эвристические тактические и позиционные признаки, время обдумывания, сессии, дни недели и соперников.
- Получать объяснимые рекомендации с примерами и сравнивать периоды одинаковой длины.
- Смотреть радар **«Профиль навыков»**: по умолчанию последние 100 партий одного формата, позиции −2…+2 пешки. Можно выбрать 50/100/200 партий или всю историю и отдельно лучшие (+2…+5) либо худшие (−5…−2) позиции. Индекс каждой игровой оси = среднее по партиям `100 × (1 − средняя min(потеря cp, 300) / 300)`; длинная партия не перевешивает короткую. Потеря матовой возможности или допущенный мат получает 300 cp; совпадение с лучшим ходом — 0. Это открытая условная шкала сохранения оценки, не рейтинг и не процент владения навыком. Показаны также средняя потеря, ошибки ≥150 cp и зевки ≥300 cp на 100 ходов, разбиение по оценке позиции и предыдущая группа того же размера. Не менее 30 оценённых ходов (или большего минимума из настроек) в пяти партиях; пропуски не превращаются в нули. Реализация отдельно показывает долю побед после устойчивого +2 среди известных результатов, минимум пять партий. Оценки по прежней формуле среднего качества напрямую не сопоставимы с v2. Калиброванного сравнения с другими игроками пока нет.
- Пользоваться разделом **«Персональный тренер»**: повторяющиеся ошибки с конкретными ходами, план на семь дней по 15 минут, отметки выполнения и сравнение частоты ошибок в двух последних группах партий одного формата и источника анализа. Отчёт использует готовые оценки и не запускает новый поиск.
- Нажимать **«Объяснить ход»** в разборе: факты из сохранённого анализа, легальный лучший ход и сохранённый вариант, вопросы для самостоятельного расчёта. Исторические оценки и неизвестная глубина явно помечены.
- Копировать компактный отчёт для нейросети и вручную вставлять его в выбранный чат. Приложение не подключается к внешней модели, не требует API-ключа и ничего не отправляет автоматически.
- Генерировать задачи из собственных ошибок: отдельная проверка Stockfish/MultiPV, решение на доске с ответами соперника, подсказки и интервальное повторение.
- Настраивать часовой пояс, границы сессий, размер выборки, режим/Hash и автоматический анализ после синхронизации; создавать резервную копию SQLite.

## Первые действия

Проверка расчётов и известные ограничения: [аудит формул](docs/FORMULA_AUDIT.md). Производные оценки старой базы обновляются при чтении; исходные партии и результаты поиска не перезаписываются. Позиции с недостаточной или граничной оценкой исключаются из точной арифметики.

Для готовых оценок откройте **«Персональный тренер»** и выберите формат. Кнопки вопросов ведут к повторяющимся ошибкам, недельному плану и прогрессу. Ссылки в примерах открывают конкретный полуход; **«Объяснить ход»** показывает сохранённые факты и вариант. Отметки плана хранятся в браузере отдельно по профилю, фильтрам и неделе (с понедельника в выбранном часовом поясе). Паттерн требует минимум трёх ошибок в трёх разных партиях и установленного в настройках числа оценённых ходов. Сравнение прогресса разделяет форматы и источники оценок; оно не доказывает эффект занятий.

1. Откройте обзор — локальная история уже доступна.
2. В разделе **«Анализ и настройки»** нажмите **«Импортировать всю историю»**: будут загружены все доступные месяцы, а также профиль и официальные рейтинги.
3. Выберите формат и период, затем **«Анализировать необработанные»**. Один фоновый worker ограничен временем/узлами; поиск не блокирует HTTP ожиданием завершения партии.
4. В разделе **«Тренировки»** начните учебный цикл: приложение подготовит до пяти позиций и предложит занятие из трёх упражнений. Неоднозначные позиции и позиции с недостаточной глубиной не попадают в задачи.

Состав локальной базы зависит от загруженной истории. Массовый Stockfish анализ при запуске самопроизвольно не начинается. Учебный цикл проверяет только выбранные позиции ваших ошибок; подробности — в docs/LEARNING_CYCLE.md.

## Методика и ограничения

Качество ходов — **собственный показатель**, не Chess.com accuracy: `100 × exp(−4 × loss_expected)`, где модельное ожидание `1/(1+exp(−cp/250))`, мат соответствует 0/1. Модель не калибрована как вероятность победы конкретного пользователя. ACPL включает нулевые потери только ваших оценённых ходов; мат не превращается в cp.

Стадии, профиль навыков и признаки вилки/связки — прозрачные эвристики. Они не гарантируют определение причины ошибки. Рейтинг в архиве — наблюдение перед партией; официальный текущий/лучший рейтинг показывается отдельно из stats API. Сессии исключают daily. Пропущенные часы/оценки не заменяются нулём. Показатели можно ограничить только новым анализом, отключив исторические оценки в настройках.

Полная база дебютной теории, точный выход из теории, Syzygy, сравнение с популяцией шахматистов, Lichess и внешний LLM-тренер не включены. Рекомендации рассчитываются локальными правилами, структурные признаки не являются полноценным экспертным позиционным объяснением. Интерфейс показывает фактические данные и эти ограничения, а не демонстрационные числа.

## Хранение и восстановление

- `data/chess.sqlite` — профили, исходные партии и PGN, версии анализа, задания, HTTP/позиционный кэш, задачи и попытки.
- `data/backups/` — резервные SQLite snapshots, создаваемые кнопкой в настройках через штатный SQLite backup API.
- Задания и позиционные checkpoints сохраняются. После аварийного завершения running возвращается в очередь; после штатного прерывания можно нажать «Продолжить».
- Для восстановления остановите приложение и сначала сохраните текущий каталог `data/` целиком; восстанавливайте snapshot в отдельный каталог/копию перед заменой основной базы. Исходные `games/` остаются дополнительным источником повторного импорта.

Приложение предназначено для одного локального владельца с несколькими шахматными профилями. HTTP слушает только `127.0.0.1`; Host/Origin проверяются. Это не многопользовательский публичный сервер. Исходящие HTTPS запросы явно проверяют сертификаты независимо от небезопасной глобальной настройки окружения.

## Проверки

```powershell
npm run check
npm test
npm run test:engine
```

Обычные тесты используют изолированные SQLite/fixtures, HTTP API и временные файлы, без Chess.com и массового анализа. Engine smoke запускает один движок, depth4, и проверяет финальную позицию партии из одного полухода. В ограниченной песочнице могут потребоваться разрешения на локальные sockets; обычный запуск Windows вне песочницы этого ограничения не имеет.

Описание реализации и проведённых проверок: [docs/IMPLEMENTATION.md](docs/IMPLEMENTATION.md). Исходный аудит — [docs/audit/AUDIT_SUMMARY.md](docs/audit/AUDIT_SUMMARY.md); это снимок состояния **до реализации**, а не текущий процент готовности.

## Структура

`app/domain.mjs` — PGN/позиции/формулы; `app/openings.mjs` — ограниченный справочник; `app/engine.mjs` — UCI/lifecycle; `app/database.mjs` — SQLite; `app/chesscom.mjs` — HTTPS/cache/retry; `app/jobs.mjs` — очередь; `app/analytics.mjs` — метрики; `app/server.mjs` — HTTP. `public/` — интерфейс без сборки; `test/` и `scripts/` — проверки. Неиспользуемый старый CLI, его конфигурация и дублирующие экспорты удалены. Документы исходного аудита сохранены как историческая документация; одноразовые скрипты её генерации удалены.

Лицензии сторонних компонентов и источники: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

Для проверки кандидатов в `!!` в уже сохранённых анализах: `node scripts/refresh-special-moves.mjs <профиль>` или `node scripts/refresh-special-moves.mjs --all`. Скрипт рассчитывает только недостающие сравнения двух альтернатив и сохраняет новые версии анализа. Старые версии остаются в базе. Новые анализы выполняют эти проверки автоматически; поиски кэшируются.

## Теоретические ходы

В просмотре партии отметка «📖 Теоретический» означает совпадение позиции и
сыгранного хода с локальной базой Lichess chess-openings (CC0). База включает
3 865 именованных линий; версия, исходники и лицензия находятся в
`resources/chess-openings`. Учитываются перестановки ходов и права рокировки.
Название варианта показывается при выборе хода. В блоке дебютного справочника
доступны переходы к последнему справочному ходу и первому выходу из базы.
Возможен последующий возврат в справочник другим порядком ходов.

Справочник не охватывает всю теорию. «Вне справочника» не означает ошибку или
новинку. Отметки не изменяют качество, точность и статистику Stockfish и работают
для ранее загруженных партий без повторного анализа и доступа к интернету.
Индекс можно пересобрать командой `node scripts/build-opening-book.mjs`.

## Изучение дебютов

«Дебюты → Изучение теории» — поиск по ECO, английскому названию или ходам,
сортировка по личному репертуару либо длине линии. Каталог содержит все 3 865
именованных вариантов локальной базы. Поиск выводит первые 100 совпадений.

Разбор позволяет листать ходы кнопками или стрелками клавиатуры. В режиме
«Проверить себя» игрок выбирает цвет, играет свои ходы, а соперник автоматически
отвечает по выбранной линии. Подсказка подсвечивает исходную клетку. Другой
легальный ход считается несовпадением с вариантом, а не шахматной ошибкой.
Результаты этой проверки действуют до смены варианта или перезапуска упражнения;
расписание обычных тренировок не меняется.

Ссылки на ранние выходы из справочника строятся по партиям текущего профиля
и общим фильтрам. Они включают выходы за обе стороны с указанием автора хода.
Количество теоретических ходов не является оценкой качества. Подробные
авторские объяснения планов для каждой из линий в базу не входят.

В разборе дебютной линии Stockfish автоматически оценивает текущую позицию
в быстром режиме и показывает до трёх продолжений. «Уточнить оценку» использует
режим из настроек. При листании устаревший расчёт отменяется; результаты позиций
кешируются на время разбора. В проверке по памяти движок запускается по кнопке
и учитывается как помощь. Расчёт передаёт полную историю выбранной линии.

## Выводы о повторяющихся ошибках

«Тренировки → Персональный тренер» показывает до трёх приоритетов: факт,
гипотезу о привычке, правило проверки и примеры из партий. Главный приоритет
выведен на Обзор, связанные ходы отмечены в разборе партии. Вкладка
«Рекомендации» объединена с тренером; прежняя ссылка `#recommendations` работает.

«Тренировать эту проблему» фиксирует исходную выборку и готовит до 5 тематических
позиций. Они доступны в «Практике → Работа над привычками». Можно пополнить набор.
Существующие задачи переиспользуются, а их расписание повторений не меняется.

Точные правила и ограничения: [docs/HABITS.md](docs/HABITS.md).

## Своя позиция

«Дебюты → Своя позиция»: расставьте фигуры нажатием или перетаскиванием,
укажите очередь хода, права рокировки и при необходимости поле взятия на проходе.
Можно вставить готовую FEN. «Найти дебют и рассчитать» проверяет расстановку,
показывает точные именованные позиции, справочные продолжения и до трёх
продолжений Stockfish. Нажмите справочный ход или «Сыграть ход»/«Проиграть линию»
у Stockfish, чтобы продолжить исследование. Доступны ход назад и возврат к корню.

Позиционный индекс игнорирует счётчики FEN, но учитывает очередь хода, рокировку
и допустимое взятие на проходе. Отсутствие совпадения не означает ошибку.
История до введённой позиции неизвестна; последующие ходы передаются движку
полностью. Последняя применённая FEN сохраняется в браузере отдельно для профиля.
Кнопки перехода есть также в разборе партии и изучении дебютной линии.

В «Своей позиции» также показана личная частота: число партий из всей загруженной
истории текущего профиля, процент и общее число появлений. Повторы внутри одной
партии считаются отдельно от числа партий. Совпадения включают начальную и
конечную позиции, игнорируют счётчики FEN и учитывают очередь хода, рокировку
и взятие на проходе. В раскрываемом списке — последние 20 подходящих партий
со ссылками на конкретные полуходы. Анализ Stockfish для подсчёта не требуется.
